Privacy policy

Last updated 14 October 2026

Daily Brief ("the app") is a personal tool run by one person, for their own use, on their own computer. This page explains what Google user data the app accesses, what it does with it, and where it goes.

What the app accesses

The app asks for one Google permission: read-only access to Gmail (gmail.readonly), for the owner's own mailboxes only. It reads the sender, subject, date and text of recent messages. It cannot send, change, archive or delete anything.

How the app uses it

The data is used for one purpose: to write the owner's daily summary. Sensitive items such as one-time codes and card numbers are removed first. The remaining text is processed by a third-party AI service only to produce the summary, under that provider's own terms.

Storage

Only short summaries are kept, on the owner's own devices and personal accounts. Full message bodies are not kept. Nothing is stored on any server run by the app.

Sharing

The app does not sell, rent or share Google user data. The AI service mentioned above acts only as a processor on the owner's behalf. No person other than the owner reads the mail content. Data is not used for advertising, and not used to train any model by the app.

Google API Services User Data Policy

Daily Brief's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be removed at any time at myaccount.google.com/permissions. Deleting the app's stored summaries removes everything it keeps. To ask about anything here, open an issue on this project's GitHub page.
